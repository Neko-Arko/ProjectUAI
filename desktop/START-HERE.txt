UAI BRIDGE 3.6.7 - WINDOWS 10/11 (64-BIT)

1. Download UAI-Bridge-3.6.7-win-x64.exe and open it directly.
   https://github.com/Project-Ptolemy/ProjectUAI/releases/download/v3.6.7/UAI-Bridge-3.6.7-win-x64.exe
2. On Workspace, if Node.js is missing, choose Get Node.js or Manual setup,
   then Check again. Click Start Cowork.
3. Load the updated Project UAI script in Roblox. It connects automatically.

The native WPF app has four pages: Workspace, Connections, Updates, and Settings.
Workspace starts and stops the bridge, copies the client script, and sets up
Node.js. Connections has the OpenCode and MCP switches and setup actions.
Updates shows app and bridge checks, downloads, and updates ready to restart.
Settings saves browser, launch, and automatic app update preferences. Navigation
adapts to smaller windows, and page content scrolls to keep actions reachable.

Chat opens in the existing Cowork browser workspace. There is no embedded chat
in the desktop window. The browser opens automatically unless you turn off
Open browser on start in Settings. Installed Node.js 18+ is detected, or the app
downloads a verified Node.js LTS runtime for your account. Node is no longer
bundled. .NET, the bridge, browser assets and client are included in the single
executable. Supporting files are prepared automatically in your private user
cache. No ZIP extraction, terminal or administrator access is needed.

OpenCode is optional and is never bundled or downloaded by this app. Install
OpenCode Desktop from https://opencode.ai, then restart the bridge to use its native
free-model workaround. The OpenCode card on Connections shows the actual CLI
version and readiness. Set the OpenCode tunnel switch before starting Cowork.
The original direct desktop workaround also remains supported; on mobile,
OpenCode requires the UAI Relay app from Discord.
UAI tools run in Roblox. The native CLI is not allowed to run desktop tools.
OpenCode Go subscriptions use https://opencode.ai/inference/go/v1 and your Go API
key directly. Go does not use the native free-model route or its mobile relay requirement.

Project UAI Free is the default when you have not configured a provider. Thank
you for your continued support. More free providers may become available.
Discord help, availability and updates: https://discord.gg/9xYyyYuKap

The bridge downloads updates automatically and applies them when work is idle.
Its version includes the Cowork web UI; use Check for bridge updates on Updates
while the bridge runs to look immediately. Old cached versions are removed
automatically. The desktop app also checks GitHub and downloads verified app
updates when Automatic app updates is enabled in Settings. Updates shows
progress and the staged version. Check for updates works manually even when
automatic downloads are off. Stop the bridge on Workspace, then choose Restart
to update app on Updates to apply a staged version immediately. Closing the app
also leaves a staged update ready for the next launch.

For Restart to update app, the old app waits for the update helper to accept the
handoff before exiting. The new app must report successful startup; otherwise the retained
version is opened again. Failed startup candidates are retried only when you
manually choose Check for updates. Unrelated or malformed GitHub release entries
are skipped. Automatic bridge updates preserve pairing; manually restarting the
app rotates its token.

The executable includes the matching client as part of its embedded files.
Use the updated Project UAI loader in your executor.
Roblox must remain running. The app does not launch Roblox or an executor.

To connect a local coding agent, click MCP setup on Connections while the bridge
is running, or open Settings > MCP in Cowork and choose Copy setup prompt.
The desktop executable also supports --mcp-stdio for
harnesses that launch local MCP commands. Roblox retains tool permissions.

If Roblox is not connecting, open UAI > Cowork. Turn on "Find desktop app
automatically" and turn off "Manual bridge enabled". Discovery checks port
28791 on this computer every four seconds. Tokens refresh automatically.

Minimize keeps the app on the Windows taskbar. Closing the window stops the
owned bridge and exits. The app never hides itself in the system tray.
Use Stop bridge to disconnect while keeping the settings window open.
Stopping interrupts active bridge requests and clears temporary picture uploads.

Port 28791 is reserved by this app while it is running. If another program
uses it, the app reports the conflict. It never terminates other programs.

This build is not code-signed. Windows may identify it as an unrecognized app.
Download only from the official release. The adjacent .sha256 and
desktop-release.json identify the executable content; they are not a publisher
signature. The app verifies its embedded files before starting the bridge.
